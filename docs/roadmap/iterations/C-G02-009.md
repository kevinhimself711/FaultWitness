# C-G02-009 — Source-Collection Failure Classification Corrective

## Status

Active. A-G02-008 remains terminally failed and is not reopened.

## Root cause

SEED-G02-0013 completed its workload stimulus, but a later source-collection command returned no
observation. The runner caught its generic `GovernanceError` and recorded `metric_fail`, although no
metric existed to compare with the oracle.

## Minimal correction

Use a typed `InfrastructureFailure` for external collection/stimulus transport that returns no result,
and persist that trial as `infra_failed`. Candidate-binding drift, explicit HTTP failure, a completed
observation that misses the oracle, and cleanup failure remain blocking. Unit tests cover the negative
classification; targeted external evidence is one read-only candidate-bound collection.

## Frozen semantics

N, 30-second spacing, 90-second deadline, oracle, recovery, permissions, Ground Truth, locked tests,
quality/performance thresholds, token/cost ceilings, and destructive-once semantics are unchanged.
