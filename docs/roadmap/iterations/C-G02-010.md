## Root cause

The pinned upstream lab manifest starts one load-generator replica with `LOCUST_USERS=10`. During
SEED-G02-0013 the lab produced fleet-wide POST 504 traces while `accounting` reached OOM restart 62.
Kubernetes still reported all Deployments Ready and the node had no MemoryPressure, so readiness
alone admitted an uncontrolled ambient-load state into the deterministic scenario.

## Scope

Rewrite the dedicated G02 lab manifest to the minimum nonzero ambient load of one user, retain all
candidate/image checks, and prove the rendered setting plus one real candidate-bound checkout with
no new OOM restart. This corrective runs no Gate scenario matrix, baseline, or model call.

- Changing scenario N, fault variants, observation spacing, 90-second oracle windows, recovery,
  quality/performance thresholds, permissions, Ground Truth, locked tests, model route, or cost.
- Increasing service resource limits or changing pinned images.
- Treating an explicit HTTP failure as resumable infrastructure evidence.

seeds while preserving only the unaffected manifest/G01 debt and 60/6/22 evidence.
