# I-0026 — Bounded Privileged Remote Script Transport Corrective

## 状态

Completed on implementation candidate `b50db666c4d73f42197bdc7136fbc0895ea26287`。
正常预计 **1h30**，仅为可观测计划值，不是 kill timeout。

## 目标

纠正 EVAL-G02-010 暴露的 Windows `CreateProcess` 命令行长度缺陷。privileged remote
script 必须通过 SSH stdin 上传到权限受限的远端临时文件；sudo 凭据只进入后续短命令的
stdin；脚本内容、凭据和 canary 均不得进入子进程命令行。

## 可证伪假设

一个大于 Windows 安全命令行预算的合成脚本能够在 mock SSH transport 中保持所有
child-process argument 有界，原字节通过 stdin 传输，执行后完成清理；任何 upload、execute
或 cleanup 的确定性错误保持 blocking，且不会产生操作员通过路径。

## 冻结验证边界

- V-G02-009 Iteration N 仍为 4；V-G02-011 Iteration N 仍为 4。
- V-G02-010 Iteration N 仍为 0，不在本 Iteration 执行 live 六阶段矩阵。
- 本地回归只证明 transport 与 runner interface，不部署、不执行 Gate L2、不调用模型。
- 完成后 `open_evidence: []`；I-0024 与 I-0025 永不重开。

## 结果

EVAL-G02-011 的 4/4 transport cases 全部通过。oversized script 只经 SSH stdin 传输；sudo
input 只进入第二条固定长度命令的 stdin；execute failure 仍清理，cleanup failure 和非法路径
均 fail closed。V-G02-009/V-G02-010/V-G02-011 的 Iteration N 分别保持 4/0/4。

远程、Gate L2、破坏性 scenario、external-service 与 model call 全部为 0，
`open_evidence: []`。证据 commit `a6d0d0c3b81a571eb33c6568ddb972ab515a9b95` 是实现
候选的 asset-only 后代，不改变运行产物或 Eval 标准。
