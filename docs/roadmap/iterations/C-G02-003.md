# C-G02-003 — Baseline LangSmith TCP Egress Probe Corrective

## Status

Active. This corrective owns one root cause exposed by EVAL-G02-026: a network-authorization
cell used an application-layer BusyBox HTTPS downloader and made no observable TCP/443 progress on
the exact baseline pod.

## Falsifiable first action

Before implementation, execute a transport-only TCP connect on the same existing probe pods. The
baseline identity must produce an allow event and the two denied identities must produce policy
reject events. If the baseline TCP connect does not reach the allow path, stop and reattribute the
failure; do not change `wget` on an unsupported hypothesis.

## Minimal scope

If the hypothesis is confirmed, replace only the external LangSmith pod-side network assertion
with an event-terminated TCP connect. Keep the separate credential-authenticated operator read,
the 60-cell Gate N, identities, expected permissions, failure classes, and every quality/performance
criterion unchanged. No preset orchestration timeout, new Eval harness, Gate L2 run, deployment,
destructive action, Bailian call, token, or cost is authorized.

Closure requires the existing targeted pytest entrypoint, a real candidate-bound same-pod seam
artifact, and `open_evidence: []`.
