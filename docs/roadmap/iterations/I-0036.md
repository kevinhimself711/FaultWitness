# I-0036 — Exact GetObject Probe Corrective

## 状态

Active。预计 **0h45**，包含 Iteration Eval；该估算仅用于观察，不是 kill timeout。

## 目标

前向修正 EVAL-G02-020 暴露的对象读取探针语义：已有 MinIO policy 只允许
`s3:GetObject`，runner 必须使用不隐含 `ListBucket` 的直接对象读取操作。不得通过扩大
权限让 `mc stat` 通过。

## 可证伪假设

三个确定性 case 能证明：canonical owner 的直接 `GetObject` 使用既有 sentinel；未授权
主体仍走同一读取操作并保持 fail closed；write probe 与隔离 policy 完全不变。

服务或模型调用。V-G02-009/010/011 Iteration N 保持 4/0/4，所有 Gate N、阈值与零容忍
语义保持不变，关闭时必须 `open_evidence: []`。
