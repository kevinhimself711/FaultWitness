# C-G02-007 — Email-Memory Monotonic-Sample Corrective

## Status

Active after terminal A-G02-006. This corrective owns only the empty `fault_samples` state exposed
by `SEED-G02-0008`; it does not reopen A-G02-006 or I-0017.

## Falsifiable hypothesis

`emailMemoryLeak` is the only fault whose active state is defined by growth between two observations.
The live observer duplicates each individual observation to ask whether it is active, so the first
sample can never satisfy the oracle or enter `fault_samples`. Retaining that first sample and using
it as the second sample's comparator must make increasing samples active while non-growth remains a
metric failure whose cleanup does not raise an indexing exception.

## Minimal scope

Only the email-memory branch's sample retention changes. The existing two observations, 30-second
spacing, 90-second deadline, exact restoration, recovery requirements, and all Gate thresholds
remain unchanged. Verification executes only `SEED-G02-0008`; no Gate L2 or model phase runs.
