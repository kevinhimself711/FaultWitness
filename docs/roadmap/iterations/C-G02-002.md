# C-G02-002 — LangSmith Access Probe Contract Corrective

## 状态

Planned。它只拥有 EVAL-G02-024 暴露的一个根因：operator-side LangSmith read probe 对
nonretryable non-success 响应既不保留可归因分类，又直接折叠成 `actual_allow: false`。

## 最小范围

- 复用现有 collector 与 pytest 入口，覆盖 credential success、transient response 和
  nonretryable classified failure 三个变化分支。
- 将现有 read-only credential operation 绑定到一个受支持的请求契约，并只保留脱敏的响应
  分类，不记录 key、workspace、payload 或可逆指纹。
- 运行一次真实 LangSmith credential seam proof；若证明 credential 本身无效，corrective
  fail closed 并上报，不替换、不轮换、不降级 expected allow。

## 成本边界

不新增专用 Eval harness，不运行 60-cell Gate N，不部署、不执行破坏性场景、不调用 Bailian，
也不更新 Master Plan、Claims 或 Gate Report。工程与三分支定向验证预计 0h30，真实 seam
proof 预计 0h05；估算不是 kill timeout。关闭时必须 `open_evidence: []`。
