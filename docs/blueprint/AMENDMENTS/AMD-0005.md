# AMD-0005 — Separate corrective work and Gate attempts from frozen Iterations

Status: accepted

Date: 2026-07-24

## Amendment

从本 amendment 生效后，Gate Master Plan 冻结的 `I-####` 列表不得因执行期失败继续递增。
单一根因修复使用 `C-G##-###`；完整统一候选执行使用 `A-G##-###`。历史 I 编号保持不可变，
仅通过 legacy registry 解释，不回溯改写。

Corrective 的成本边界为根因修复、变化分支的定向测试、必要的最小真实 seam proof 与自身
证据。它不包含完整 Gate Eval、Gate L2 N、全局 Claims、Master Plan 预算重算、Validation
final-path 重定向或 Gate closure。普通 corrective 禁止新增 bespoke Eval harness。

后续 Master Plan 的每个计划内 I 记录必须声明外部 seam；每个已声明 seam 必须在 owning I
关闭前具备真实 operation proof、只读 failure diagnostic 与 artifact 路径。mock/memory-only
readiness 不足以授权对应 live Gate operation。

Gate attempt 只编排冻结 runner，不得含实现、fixture、framework、阈值或指标变化。确定性
失败产生终态 attempt evidence；下一修复使用新的 C ID，而不是新增 I 编号或重开旧记录。
Gate attempt 禁止现场新增诊断工具；只使用 owning work 已冻结的诊断 runner，并在失败
artifact 中披露诊断调用数和命令构造错误数。

## Unchanged contracts

本 amendment 不改变 G02 或后续 Gate 的样本 N、95% CI、质量/性能指标、zero-tolerance
标准、权限、Ground Truth、locked test、health window、模型 route、token/费用上限、cache、
resume、destructive-once 或 failure classification。无 preset wall-clock kill timeout 的规则不变。
