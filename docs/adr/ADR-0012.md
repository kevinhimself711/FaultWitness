# ADR-0012: Compare Three Diagnosis-Only Baselines on Shared Observation Packets

Status: accepted

Date: 2026-07-23

## Context

G02 需要可解释的非 Agent 基线和 live 模型对照，但不应提前实现 G03 Runtime。若每个
baseline 重新注入故障，实验差异会混入环境漂移，并把 32 次注入扩大为 192 次 live matrix。

## Decision

每个 seed 只注入一次并冻结一个 canonical observation packet，随后由以下 baseline 复用：

1. Deterministic workflow：固定规则，无模型、无 GT。
2. Naive ReAct：固定 Qwen snapshot，只读 observability tools，四个 model turns、六个 tool
   calls、8,000 input 和 1,024 output token cap。
3. no-RAG：同一 model 的一次 structured completion，无 tool/retrieval，4,000 input 和 512
   output token cap。

两个 live baseline 对 32 seeds 各运行三次，共 192 Gate trials。Iteration 只用两个非 seed
synthetic cases 形成四个 live smoke trials。Scorer 是确定性代码，不使用 LLM judge。95%
percentile bootstrap 按 32 case IDs 聚类，`B=2,000`，RNG seed 来自 dataset digest。

错误、malformed、schema-invalid 或预算耗尽是被计分的候选结果，不能重跑取幸运值。只有
传输、DNS、TLS、429、5xx 或 timeout 在固定 retry 后仍失败时记为 `infra_failed` 并续跑该
trial。任何 fallback 都使候选失败。

## Consequences

G02 只建立 baseline 与七项冻结质量下限的测量关系，不要求 baseline 达标。Agent Runtime、
RAG、多模型族、LLM judge 和 human agreement 留待后续 Gate。
