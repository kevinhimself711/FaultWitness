# ADR-0015: Replace per-work-item governance with release-level provenance

- Status: Accepted
- Date: 2026-07-26
- Scope: G03 and later governance; G00–G02 remain immutable
- Supersedes: ADR-0014 as a forward workflow; narrows ADR-0009 and ADR-0013 to the G02 legacy epoch

## Context

G02 closed rigorously, but its per-Iteration/corrective/attempt lifecycle, multi-SHA identity,
changed-path authorization, state mirrors, and candidate-wide cache invalidation dominated delivery
cost. A real seam passed and was followed by roughly six hours of governance synchronization before
the next experiment. The final direct-debug period removed those prerequisites while preserving all
frozen samples, thresholds, and evidence, and execution became stable.

## Decision

Future Gates use one current state file, one frozen Gate Plan, atomic experiment journals, named
semantic checkpoints, one Gate Report, and one release manifest. Git SHA is factual producer/release
provenance only. Documentation and lifecycle changes do not invalidate experiments.

G00–G02 I/C/A, manifests, bindings, and policies remain immutable at their existing paths and are
removed from active CI and registries. Historical reproduction requires the Gate tag.

## Consequences

- Small deterministic defects use a direct root-cause/fix/targeted-proof/affected-replay loop.
- No future per-Iteration YAML, corrective, Gate-attempt, activation, evidence-head, or closure
  state chain exists.
- CI loses history scans and SHA/status checks but retains contracts, tests, lint, documentation,
  cross-platform execution, and architecture/security invariants.
- Eval metrics and performance criteria are unchanged.
