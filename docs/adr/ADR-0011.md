# ADR-0011: Isolate G02 Ground Truth and Locked Tests by Identity and Prefix

Status: accepted

Date: 2026-07-23

## Context

G02 首次产生 seed ground truth，并预注册未来 locked cases。仅依赖代码约定无法证明
Agent、普通开发凭据和 baseline runtime 不能读取答案；同时，提前物化 160 个 case 会
越过 G07 边界。

## Decision

使用 `fw-sut`、`fw-baseline` 和现有 `fw-eval` 三个 trust zone。MinIO bucket
`faultwitness-eval` 下固定五个 G02 prefix：`g02/scenarios/`、`g02/trials/`、
`g02/ground-truth/`、`g02/locked-tests/`、`g02/evidence/`。

身份固定为 `scenario-controller`、`baseline-agent`、`sealed-evaluator` 和用于负例的
`ordinary-developer`。Controller 不能读 GT/locked；baseline 只能访问自己的 observation
与 trial；sealed evaluator 可读 GT/locked/trials 但不能修改 SUT；developer 不能读私有
trial、evidence、GT 或 locked 内容。NetworkPolicy 同时禁止 baseline 访问 `fw-eval`。

160-row registry 只含 ID、family、split、difficulty 和 G07 GT placeholder；G02 不创建对应
case 或 answer object。三个 runtime image 的 build context 排除 GT、locked fixtures 和该
registry。

## Verification

I-0018 当期证明新增身份、prefix 和 writer 的 policy 与 canary 属性。Gate 在统一候选上执行
60-cell live access matrix 和 22-cell Secret/PII matrix。Agent credential 与 ordinary developer
credential 均有具名读取拒绝 fixture。

## Consequences

任何新增 principal、persistence/egress surface 或 prefix 必须在引入它的 Iteration 增量验证，
不得留给最终 Gate 临时补框架。
