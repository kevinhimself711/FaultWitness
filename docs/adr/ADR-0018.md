# ADR-0018: Retract the +0.10 Margin Anchored on Failed Instrument Readings

Status: accepted

Date: 2026-09-10

## Context

The G03 quality floor `max(0.70, best_baseline + 0.10)` resolves to `1.0167` once
`best_baseline` is `naive_react` 0.9167 — unsatisfiable on the unit interval. The same rule is
restated in nine places, all copies of one decision:

- `docs/gates/G03/PLAN.md:22-24`
- `docs/audit/2026-07-28/gates/G03.md:31`, `:523`, `:603`
- `docs/audit/2026-07-28/README.md:164`, `:198`
- `docs/audit/2026-07-28/FINAL_PLAN_PROPOSED.md:175-176`
- `docs/audit/2026-07-28/FINAL_PLAN_REVIEW.md:99`
- `docs/blueprint/FINAL_PLAN.md:367`

## Named instrument defect

`+0.10` was anchored on G02's measured `deterministic 0.500` and live `0.000`. Both were later
shown to be instrument failures: a rule-table defect and a label-format artifact respectively.
The margin was pinned to two broken readings before any valid measurement existed. Cost, per
`docs/engineering/POSTMORTEM_MEASURE_BEFORE_FREEZE.md`: 3 metric versions, 7 amendments,
8 `-invalidated-*` run directories, 3 voided rounds across r1-r9.

`docs/governance/GOVERNANCE_V2.md:94` calls an unreachable frozen target a design-defect signal
to be reported; `:96` permits re-deriving the reference point when a specific instrument defect
is named and the target's form and margin are preserved.

## Decision

The **numeric value** of the margin returns to undetermined: "pending — set by the first run
that passes the validity checks".

The target's **form is unchanged**: still `max(floor, best_baseline + margin)`. The floor is not
lowered, `naive_react` is not dropped, `score_result_v3` is not relaxed, and the target is not
capped. Only the margin is undetermined, because the measurement that produced it is void.

## Unfreezing conditions

All three, in order: leakage probe passes; divergence check passes; the first `naive_react`
baseline from a validity-checked run is committed. The margin is then derived from that
measurement and recorded in `PLAN.md`.

## Not done here

No floor lowered. No comparison arm removed. No predicate changed. No target capped. This ADR
changes documentation only; the enforced expression in `src/` is untouched and still resolves
to `1.0167`, so it remains blocking until a separate implementation change carries this
decision into code.
